### 决策记录模板

每条记录包含：
- **标题**: 决策名称
- **日期**: 决策日期
- **状态**: 已采纳 / 已废弃 / 被取代 / 待决策
- **背景**: 为什么要做这个决策
- **方案**: 最终选择 + 原因
- **备选方案**: 考虑过的其他选项
- **后果**: 正面/负面影响
- **关联决策**: 相关 ADR 链接
