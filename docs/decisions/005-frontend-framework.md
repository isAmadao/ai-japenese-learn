# 005 · 前端框架

- **日期**: 2026-06-04
- **状态**: ✅ 已采纳

## 背景

需要一个现代化前端框架构建学习应用 UI，需要 SPA 路由、状态管理、HTTP 客户端。

## 方案

| 组件 | 选型 | 原因 |
|------|------|------|
| 框架 | Vue 3 (Composition API) | 轻量、学习曲线平缓、响应式系统 |
| 构建工具 | Vite | 极速 HMR、原生 ESM |
| 路由 | Vue Router 4 | Vue 官方标准 |
| 状态管理 | Pinia | Vue 3 官方推荐，TypeScript 友好 |
| HTTP | Axios | 拦截器、请求取消、广泛使用 |
| 语言 | TypeScript | 类型安全、IDE 友好 |

## 页面路由

| 路径 | 页面 | 功能 |
|------|------|------|
| `/` | Home | 随机 5 词、收藏、换一批、详情入口 |
| `/favorites` | Favorites | 收藏列表(6列)、多选生成文章 |
| `/word/:id` | WordDetail | 单词详情、例句、朗读、关联文章 |
| `/article/:id` | ArticleDetail | 文章中日对照、朗读、单词链接 |

## 问题记录

### @/ 路径别名

Vite 的 `resolve.alias` 需要显式配置，仅靠 tsconfig.json 的 `paths` 无效。

```typescript
// vite.config.ts
resolve: {
  alias: { '@': resolve(__dirname, 'src') },
}
```

## 后果

- ✅ TypScript 覆盖所有 API 类型，前后端类型一致
- ✅ Vite proxy 代理 `/api` 到后端，开发时无跨域问题
- ⚠️ Vue 3 Composition API + TypeScript 对新手有一定学习成本
